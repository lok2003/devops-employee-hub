# DevOps Employee Hub

React frontend for the Kubernetes/DevOps portfolio project.

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

The frontend currently uses local mock data. `src/services/api.js` is ready for the future REST backend.

## Features
- Login screen
- Dashboard
- Employee CRUD UI
- Departments
- Attendance
- Profile
- Responsive design
- Axios API layer
